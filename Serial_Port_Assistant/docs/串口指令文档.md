# VOFA+ 串口指令文档（温度控制仿真测试分支）

> 适用分支：`feature/vofa-temp-sim`
>
> 场景：通过控制加热电流来控制温度。温度环 PI（`temp_kp` / `temp_ki`）由温度误差计算电流指令，电流执行器按一阶惯性跟随（`temp_kd` 调节阻尼），一阶热模型仿真温度并反馈闭环。`temp_sw` 为温度控制开关（1 = 闭环自动控制，0 = 开环）。
>
> 代码位置：`modules/temp_sim.c` / `modules/temp_sim.h`，VOFA 通道定义见 `modules/vofa.h`。

---

## 1. 串口参数

| 项目       | 值       |
| ---------- | -------- |
| 串口外设   | USART3   |
| 波特率     | 115200   |
| 数据位     | 8        |
| 停止位     | 1        |
| 校验位     | 无       |
| 帧格式     | JustFloat（设备 → 上位机） |
| 指令格式   | FireWater（上位机 → 设备）  |

## 2. JustFloat 上报帧（设备 → 上位机，10ms 一帧）

### 2.1 帧格式

每帧由 **N 个 float32 通道值 + 4 字节帧尾** 组成，小端序：

```
[ float ch0 ][ float ch1 ] ... [ float chN-1 ][ 0x00 0x00 0x80 0x7F ]
```

- 帧尾 `0x00 0x00 0x80 0x7F` 是 JustFloat 协议规定的帧结束标志，VOFA+ 据此切帧；
- 本测试固件帧内共 8 个 float（`VOFA_TX_CH_SUM = 8`），即温度场景全部有效通道
  （原有泵/传感器通道已在 `vofa.h` 中注释，不参与发送）；
- 发送周期 10ms，时间戳通道每帧 +0.01（单位：秒）。

### 2.2 温度场景通道列表（按帧内顺序）

| 帧内序号 | 通道名         | 含义                         | 单位     | 备注                         |
| -------- | -------------- | ---------------------------- | -------- | ---------------------------- |
| 0        | `temp_kp`      | 温度环比例系数实时值         | A/°C     | 下发参数的实时回显           |
| 1        | `temp_ki`      | 温度环积分系数实时值         | A/(°C·s) | 下发参数的实时回显           |
| 2        | `temp_kd`      | 电流响应阻尼系数实时值       | 无单位   | 下发参数的实时回显           |
| 3        | `temp_sw`      | 温度控制开关实时值           | 0/1      | 1 = 闭环，0 = 开环           |
| 4        | `temp_tar`     | 目标温度实时值               | °C       | 下发参数的实时回显           |
| 5        | `temp_value`   | 仿真温度实时值               | °C       | 温度模型输出（反馈量）       |
| 6        | `temp_current` | 实际控制电流实时值           | A        | 电流执行器输出               |
| 7        | `timestamp`    | 时间戳（单位秒，每帧 +0.01，作 X 轴） | s       | 从 0 开始累加                |

> VOFA+ 中数据通道设为 8 即可（对应帧内全部 8 个 float）。

## 3. FireWater 参数设置指令（上位机 → 设备）

### 3.1 指令格式

FireWater 文本模式，`关键字:数值;` 成对出现，一行一帧：

```
temp_kp:20;temp_ki:0.5;temp_kd:0.5;temp_sw:1;temp_tar:37;
```

- 关键字与数值之间用英文冒号 `:` 分隔，每组以英文分号 `;` 结尾；
- 可**只发送需要修改的参数**，未出现的参数保持上一次的值；
- 发送后设备在 10ms 内解析并生效，下一帧 JustFloat 中即可看到参数回显更新。

### 3.2 参数说明

| 关键字      | 含义                     | 单位     | 取值范围      | 默认值 | 说明                                   |
| ----------- | ------------------------ | -------- | ------------- | ------ | -------------------------------------- |
| `temp_kp`   | 温度环比例系数           | A/°C     | ≥ 0           | 20.0   | 温度误差越大，输出电流越大             |
| `temp_ki`   | 温度环积分系数           | A/(°C·s) | ≥ 0           | 0.5    | 消除稳态误差，过大易震荡               |
| `temp_kd`| 电流响应阻尼系数         | 无单位   | ≥ 0           | 0.5    | 越大电流响应越钝，抑制温度过冲         |
| `temp_sw`   | 温度控制开关             | 0/1      | 0 或 1        | 1.0    | 1 = 闭环自动控制；0 = 开环（电流为 0，温度自然回落） |
| `temp_tar`  | 目标温度                 | °C       | 0 ~ 100       | 37.0   | 闭环时温度将爬升并稳定到该值           |

### 3.3 指令示例

```text
# 闭环控制：目标 37°C（默认参数即可），温度从 25°C 爬升至 37°C 并稳定
temp_sw:1;temp_tar:37;

# 调大比例系数加快响应
temp_kp:40;temp_ki:0.5;

# 增大阻尼抑制过冲
temp_kd:2.0;

# 切回开环，电流归零，温度回落
temp_sw:0;
```

## 4. VOFA+ 快速使用步骤

1. 打开 VOFA+，选择 USART3 对应的串口，波特率 115200；
2. 协议选择 **JustFloat**：数据通道设为 8，即可看到 `temp_kp`~`timestamp` 8 路波形；
3. 在下方 **FireWater** 输入框发送参数指令（见 3.3 示例），例如：
   `temp_sw:1;temp_tar:37;`
4. 观察：`temp_value` 从环境温度（默认 25°C）爬升至 37°C 并稳定；
   `timestamp` 线性递增（0.01s/帧）可作为 X 轴；`temp_current` 显示控制电流；
5. 发送 `temp_sw:0;` 验证开环：电流归零，温度指数回落到环境温度。

## 5. 控制逻辑与模型说明（便于理解波形）

```
temp_tar ─┐
          ├─ 误差 e ─→ 温度环 PI（temp_kp / temp_ki）─→ 电流指令
temp_value┘                                                │
                                                          ▼
                                          电流执行器（一阶惯性，temp_kd 阻尼）
                                                          │
                                                          ▼
                                          热模型（加热 P=I²·R，散热 k·(T-Tamb)）
                                                          │
                                                          ▼
                                                     temp_value（反馈）
```

- 模型常量（`temp_sim.h` 中可调宏）：环境温度 25°C、加热电阻 1.0Ω、热容 100 J/°C、散热系数 2.0 W/°C、电流上限 5A；
- 满功率（5A）稳态温升约 12.5°C，可覆盖常见目标温度（如 37°C）；
- 模型时间常数约 50s，波形在 VOFA+ 上数十秒内清晰可见；
- 积分项限幅 ±5（防 windup），输出限幅 0~5A，参数非法（负值）自动钳位。
